## Prompt

Create a modern, minimalist illustration showing three friendly robots working together:

1. **Left robot (Antigravity)**: A thoughtful robot with a glowing brain/lightbulb, representing planning and orchestration. Color: Purple/Violet tones.

2. **Center robot (Gemini CLI)**: A creative robot with a paintbrush and palette, generating colorful images. Color: Blue/Cyan tones.

3. **Right robot (Jules)**: A busy robot typing on a floating keyboard, with code symbols around it. Color: Green/Teal tones.

**Style requirements**:
- Dark background (#1a1a2e or similar)
- Flat design, slightly 3D feel
- Soft glow effects
- Professional but friendly
- No text in the image

**Mood**: Collaborative, futuristic, developer-friendly
