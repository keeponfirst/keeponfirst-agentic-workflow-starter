# BabyLog Home Screen Design Request

## Project Context
BabyLog is a premium baby tracking app for new parents. The app should feel warm, soft, hand-drawn, and picture-book inspired. It should be calm, reassuring, and emotionally supportive, never clinical or technical.

## Screen: Home Screen (Main Dashboard)

### Visual Style
- **Background**: Warm cream tone (#F5F1E8)
- **UI Elements**: Soft, rounded cards with generous spacing and very subtle shadows
- **Typography**: Rounded, friendly, and easy to read
- **Illustrations**: Hand-drawn and playful, inspired by children's picture books
- **Overall Feel**: Gentle, minimal, and premium

### Layout Requirements
- Mobile-first design (iOS/Android)
- One-handed use friendly (bottom-heavy layout)
- Large touch targets (minimum 44x44pt)
- Generous spacing between elements

### Key Components
1. **Header Section**
   - Baby's name or "Today" title
   - Soft, rounded font
   - Optional: Small hand-drawn illustration

2. **Quick Actions Card**
   - Large, rounded card with soft shadow
   - 4-6 quick action buttons:
     - Feed (bottle icon)
     - Diaper (diaper icon)
     - Sleep (moon icon)
     - Play (toy icon)
   - Icons should be hand-drawn style, warm colors

3. **Today's Summary Card**
   - Today's feeding count
   - Today's diaper changes
   - Today's sleep duration
   - Soft, rounded numbers with friendly icons

4. **Recent Activity Feed**
   - List of recent activities
   - Each item: icon + time + description
   - Soft dividers, plenty of whitespace

5. **Bottom Navigation** (if needed)
   - Home, Log, Stats, Settings
   - Large, rounded icons
   - Warm accent color

### Color Palette
- Background: #F5F1E8 (warm cream)
- Primary: #FFB6C1 (soft pink) or #B0E0E6 (soft blue)
- Accent: #FFD700 (warm gold)
- Text: #4A4A4A (soft dark gray)
- Cards: #FFFFFF (white) with subtle shadow

### Typography
- Headings: Rounded, friendly sans-serif (e.g., Rounded Mplus, Quicksand)
- Body: Easy to read, slightly larger than typical (16-18pt)
- Numbers: Bold, friendly, easy to scan

### Interactions
- All buttons should have gentle press animations
- Cards should have subtle hover/lift effects
- Transitions should be smooth and calming
- No harsh animations or jarring transitions

### Accessibility
- High contrast for text
- Large touch targets
- Clear visual hierarchy
- Support for dynamic type sizes

## Design Prompt for Stitch

Design a mobile home screen for BabyLog, a premium baby tracking app. The screen should have:

1. A warm cream background (#F5F1E8)
2. A header showing "Today" with a soft, rounded font
3. A large quick actions card with 4-6 rounded buttons (Feed, Diaper, Sleep, Play) with hand-drawn style icons
4. A today's summary card showing feeding count, diaper changes, and sleep duration with friendly icons
5. A recent activity feed with soft dividers and plenty of whitespace
6. Bottom navigation with Home, Log, Stats, Settings icons

The overall style should be warm, soft, hand-drawn, and picture-book inspired. Use rounded corners, generous spacing, subtle shadows, and warm colors (soft pink #FFB6C1, soft blue #B0E0E6, warm gold #FFD700). Typography should be rounded and friendly. The design should feel calm, reassuring, and emotionally supportive, suitable for use while holding a baby with one hand.
