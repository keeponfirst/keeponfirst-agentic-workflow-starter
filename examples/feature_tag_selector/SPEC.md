# 功能規格：標籤選擇器

## 概述

讓使用者能夠為筆記新增多個標籤，方便分類和搜尋。

## 使用情境

1. **建立標籤**：使用者可以建立新標籤（名稱 + 顏色）
2. **選擇標籤**：在筆記編輯時，選擇要套用的標籤
3. **篩選內容**：透過標籤篩選筆記清單

## UI 規格

```
├──────────────────────────────────────────┤

│ │ 工作   │ │ 個人   │ │ 靈感   │  ...    │
│ └────────┘ └────────┘ └────────┘         │
└──────────────────────────────────────────┘
```

### 互動行為

| 操作 | 行為 |
|------|------|
| 點擊標籤 | 切換選取狀態 |
| 長按標籤 | 顯示編輯選單 |
| 點擊 + | 新增標籤 |
| 左右滑動 | 捲動更多標籤 |

### 視覺規格

| 元素 | 規格 |
|------|------|
| 標籤高度 | 32pt |
| 標籤圓角 | 16pt (capsule) |
| 標籤間距 | 8pt |
| 容器 padding | 16pt |
