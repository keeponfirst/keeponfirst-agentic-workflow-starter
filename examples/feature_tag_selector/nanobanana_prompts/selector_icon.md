## Prompt

```
Generate a single icon with the following specifications:

## Icon Description
A simple price tag or label icon, suitable for a notes app tag feature

## Style Guidelines
- Style: filled, minimal
- Color: #007AFF (Apple Blue)
- Background: Transparent
- Size: 24x24 pixels

## Technical Requirements
- Export as PNG with transparency
- Clean edges, no artifacts
- Centered within canvas
- Simple, recognizable shape

## Context
This icon will be used for: Tag selector header in a notes app. 
Should be simple enough to be legible at 24x24 size.
```
