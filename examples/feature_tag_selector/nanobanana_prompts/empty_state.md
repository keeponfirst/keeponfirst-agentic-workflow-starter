# Empty State Prompt

這是產生「無標籤」empty state 插圖的 Gemini CLI prompt。

---

## 輸出

- **路徑**：`assets/generated/illustrations/tags_empty_state.png`
- **尺寸**：200x200 pixels

---

## Prompt

```
Generate a single empty state illustration with the following specifications:

## Illustration Description
An empty label holder or tag box, looking friendly and inviting.
The illustration should suggest that adding tags is easy and beneficial.

## Emotional Tone
- Mood: friendly, encouraging
- Message conveyed: "Nothing here yet, but it's easy to start!"

## Style Guidelines
- Style: flat illustration with soft colors
- Color palette: 
  - Primary: Soft blue (#007AFF at 30% opacity)
  - Secondary: Light gray (#E5E5EA)
  - Accent: White
- Background: Transparent
- Size: 200x200 pixels

## Technical Requirements
- Export as PNG with transparency
- Clean, simple shapes
- Centered composition
- Not too detailed (should load fast and look good at smaller sizes)

## Context
- App/Feature: Notes app, Tag selector section
- When shown: When user has not created any tags yet
- Accompanying text: "尚無標籤"
```
